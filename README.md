# Блокировка экрана для МОС 12

Программа закрывает все мониторы фоновой картинкой. Для разблокировки введите PIN в поле на основном мониторе. Можно использовать физическую или экранную цифровую клавиатуру.

## Установка и обновление

Пакет версии **1.1.2** предназначен для МОС Desktop 12 x86_64 с KDE Plasma 5 в сеансе X11. Чтобы проверить тип сеанса, откройте терминал на рабочем столе МОС и выполните `echo "$XDG_SESSION_TYPE"`. Ожидаемый результат — `x11`.

Сохраните файл `mos-screen-lock-1.1.2-1.noarch.rpm` на компьютере с МОС. Откройте терминал в папке с пакетом и выполните:

```bash
sudo dnf install ./mos-screen-lock-1.1.2-1.noarch.rpm
sudo mos-screen-lock --set-pin
```

Введите новый PIN из **6–12 цифр** и подтвердите его. Ввод в терминале скрыт. При обновлении ранее заданный PIN сохраняется, поэтому вторую команду можно пропустить.

После первой установки выйдите из графического сеанса и войдите снова, чтобы Plasma загрузила виджет. Если значок **«Блокировка экрана»** не появился, откройте настройки системного лотка KDE и установите для него **«Всегда показывать»**.

## Блокировка и разблокировка

1. В видимой части системного лотка удерживайте левую кнопку мыши на значке **«Блокировка экрана»** не менее **700 мс**, затем отпустите её. Короткий клик игнорируется.
2. Введите PIN. Чтобы воспользоваться мышью, нажмите **«Показать клавиатуру»** и наберите цифры на экране. Кнопка **⌫** стирает последнюю цифру. Кнопка **«Скрыть клавиатуру»** сворачивает цифровую панель.
3. Нажмите **«Разблокировать»** или клавишу **Enter**. После неверного PIN подождите две секунды и повторите ввод.

При каждой блокировке экранная клавиатура изначально скрыта.

## Замена PIN или фоновой картинки

Чтобы сменить PIN или задать новый, повторите `sudo mos-screen-lock --set-pin`.

Чтобы установить свой фон, сохраните картинку в формате PNG и выполните в папке с картинкой:

```bash
sudo install -d /etc/mos-screen-lock
sudo install -m 0644 ./my-picture.png /etc/mos-screen-lock/background.png
```

Новое изображение появится при следующей блокировке. Если переименовать пользовательский файл `background.png`, программа снова покажет стандартный фон.

## Удаление

```bash
sudo dnf remove mos-screen-lock
```

PIN и пользовательская картинка хранятся в `/etc/mos-screen-lock/` и сохраняются после удаления RPM.

## Ограничения

Приложение перехватывает клавиатуру и мышь в X11. Системное переключение в текстовую консоль и принудительное завершение процесса остаются возможными. Для системной блокировки сеанса используйте штатную блокировку KDE.
